# Start here

You are working on AgentWebUI. Read [README.md](README.md) first: it covers what the app does, how to run it and how
to configure it.

Rules:

- **Tiny:** no new dependency or service.
- **No dead controls.**
- **Match the design canvas.**
- **Configuration in `.env` only.**
- **Tests for every server change.**
- **One branch and one pull request into `main` per milestone.**
- **Never commit `.env` or `data/`.**
