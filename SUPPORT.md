# Getting help

- **Setup, configuration and how-to questions:** ask in
  [Q&A](https://github.com/HackersHostel/AgentWebUI/discussions/categories/q-a). Search it first; your question may
  already have an answer.
- **Something is broken:** open a [bug report](https://github.com/HackersHostel/AgentWebUI/issues/new/choose).
- **An agent or model provider won't work:** use the *Agent or provider compatibility* issue form.
- **An idea:** start in [Ideas](https://github.com/HackersHostel/AgentWebUI/discussions/categories/ideas).
- **A security problem:** report it privately, as [SECURITY.md](SECURITY.md) describes.

Before asking, the [README](README.md) covers running it, putting it on a server, and every setting, and
[`.env.example`](.env.example) explains each setting in a line.

AgentWebUI is maintained by volunteers, so answers can take a few days. Clear steps and logs get the fastest replies.
